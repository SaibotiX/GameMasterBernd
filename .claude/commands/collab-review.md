Review the MAINTAINER's collaboration in the current conversation — not
the AI's work, not the game. This is the one sanctioned entry into
`research/collaboration/`; outside this command that folder stays unread.

Follow `research/collaboration/README.md` exactly. In short:

1. **Read the kit**: `research/collaboration/README.md`, `taxonomy.md`,
   `registry.md`, and the MOST RECENT review in `reviews/` only (older
   ones live in the registry's trends — don't reload them all).
2. **Free notes first**: re-read this conversation from the start and
   note concrete maintainer moments — what steered well, what cost a
   round-trip, what was guessed on their behalf — each with a short
   quote or unambiguous pointer. Note BEFORE classifying. Judge only
   what is visible in this session; work-style only, never personality.
3. **Classify** into CS-/CI- classes; unmatched patterns become
   CS-NEW-n / CI-NEW-n with a one-line definition (promote to
   taxonomy.md when they recur across reviews).
4. **Trend against the registry**: for every class seen (or notably
   absent), mark IMPROVED / RECURRING(×streak) / NEW / RETIRED. Check
   the standing "current focus" FIRST and say plainly whether it was
   practiced — a recurrence softened or unremarked is a failed review
   (the honesty clause; see the MIT sycophancy finding in the README).
   Balance is required in both directions: name strengths so they don't
   erode, name recurrences with their streak.
5. **Write** `reviews/<YYYY-MM-DD>-<n>.md` (immutable once written; next
   review gets a new file) in the seeded review's shape: verdict
   paragraph, SBI findings (Situation → Behavior → Impact) per class,
   registry deltas, ONE focus for next session. Update `registry.md`
   (dated, never silently rewritten) and refresh `handoff.md` ONLY if a
   stable pattern changed (keep it ≤10 lines, mechanical
   instructions-to-the-AI, zero judgments about the person).
6. **End by telling the maintainer**: what improved since last review,
   what recurred (with streak), and the single focus for next session —
   three short paragraphs, no more.

Hard rules: findings cite concrete conversation moments; the review never
reads other `research/collaboration/` reviews beyond the latest; nothing
from this folder is ever quoted into other work or memory; if the session
holds too little maintainer interaction to judge fairly, say so and skip
the review rather than inventing one.
